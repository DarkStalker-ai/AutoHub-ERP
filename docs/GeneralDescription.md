# Загальний опис AutoHub ERP

**Версія програмного забезпечення:** 0.2.0-beta  
**Версія документа:** 1.0  
**Тип програмного забезпечення:** вебзастосунок

## 1. Призначення системи

AutoHub ERP — навчальна вебсистема для автоматизації окремих процесів діяльності автосалону. Поточна версія призначена для ведення обліку автомобілів, марок автомобілів і клієнтів, керування обліковими записами користувачів, перегляду журналу подій, налаштування параметрів системи та отримання базової звітної інформації.

Система перебуває в розробці. Функції продажів, резервування, гарантійного обслуговування та роботи майстерні в поточній версії не слід вважати реалізованими.

## 2. Основні функціональні можливості

### 2.1. Автентифікація та авторизація
- вхід користувача за логіном і паролем;
- розмежування доступу за ролями `Admin` і `Manager`;
- завершення сеансу роботи;
- обмеження доступу до адміністративних функцій.

### 2.2. Облік автомобілів
- перегляд переліку автомобілів;
- перегляд детальної інформації;
- створення та редагування записів;
- пошук, фільтрація та впорядкування даних відповідно до реалізованих параметрів;
- видалення записів відповідно до прав доступу.

### 2.3. Довідник марок
- перегляд марок автомобілів;
- створення та редагування записів;
- використання довідника під час роботи з автомобілями.

### 2.4. Облік клієнтів
- перегляд списку клієнтів;
- перегляд детальної інформації;
- створення та редагування записів;
- пошук і впорядкування даних відповідно до реалізованих параметрів.

### 2.5. Адміністрування
- перегляд облікових записів;
- створення користувачів із ролями `Admin` або `Manager`;
- активація та деактивація облікових записів;
- перегляд журналу аудиту;
- фільтрація журналу за текстом, типом дії та датами;
- редагування системних параметрів.

### 2.6. Звіти
Поточна версія містить базовий звітний модуль із узагальненими показниками щодо автомобілів, зокрема розподілом за марками. Склад показників визначається реалізацією поточної версії.

## 3. Категорії користувачів

**Адміністратор (`Admin`)** має доступ до адміністративної підсистеми: керування користувачами, журналу подій і системних параметрів. Також доступність операцій видалення визначається перевірками авторизації в контролерах.

**Менеджер (`Manager`)** працює з основними обліковими функціями в межах дозволів, визначених застосунком. Адміністративні функції обмежені.

## 4. Архітектура та принцип роботи

AutoHub ERP реалізовано як вебзастосунок за архітектурним підходом ASP.NET Core MVC:
- **Models** — моделі даних і допоміжні моделі представлень;
- **Views** — Razor-представлення інтерфейсу;
- **Controllers** — обробка HTTP-запитів і взаємодія з моделями;
- **Services** — службова логіка, зокрема журналювання подій;
- **Data** — контекст Entity Framework Core та ініціалізація бази даних.

Користувач взаємодіє із системою через веббраузер. Серверна частина обробляє запити, звертається до PostgreSQL через Entity Framework Core та повертає сформовані сторінки.

## 6. Вимоги до середовища

Для розробки та локального запуску потрібні:
- Windows, Linux або інша операційна система, що підтримується .NET 9;
- .NET 9 SDK;
- PostgreSQL Server;
- доступ до бази даних із параметрами, заданими в конфігурації;
- сучасний веббраузер.

Для запуску опублікованої версії на сервері потрібне відповідне середовище виконання .NET 9. Для розміщення за IIS на Windows використовується сумісний ASP.NET Core Hosting Bundle. Конкретний варіант хостингу визначається середовищем розгортання.

## 7. Обмеження поточної версії

Версія 0.2.0-beta є проміжною навчальною версією. Вона не повинна розглядатися як завершена комерційна ERP-система. Функції, позначені в плані проєкту як заплановані, зокрема продажі, резервування та гарантійне обслуговування, не описуються як доступні користувачеві.
